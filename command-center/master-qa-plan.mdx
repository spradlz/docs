## The machine (what's novel here)

- **The Coverage Ledger** — the checklist is *generated from the code* (every route, nav item,
  button), so nothing is skipped because nobody thought of it. Green/red/unwalked, visible here.
- **The Render Lint** — a nightly sweep that reads every live card like a human and flags the
  "An agent edited a lead" class automatically, forever. Machine-caught, never Zach-caught.
- **Docs = proof** — the ~300 drifted docs move to a legacy shadow set; canonical docs are written
  ONLY as each lane goes green. The documentation becomes incapable of describing the unverified.
- **The Build Log** — every fix made during QA, one line each, running record → the changelog.
