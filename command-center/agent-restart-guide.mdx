## The buttons (what each one actually does)

| Button | What happens on the Mac |
|---|---|
| ▶ Start | Creates the agent's tmux session if missing, opens an iTerm window, launches `claude` with that agent's saved model, and auto-sends the "you are lee" wake-up line ~12s later |
| ⟳ Restart | Sends `/exit` to the running session, waits, relaunches the same way |
| ■ Stop | Sends `/exit` (falls back to Ctrl+C if frozen); the tmux session stays alive |
| ✕ Kill | Kills the tmux session entirely — for hard freezes |
| ⌨ Terminal | Opens an iTerm window attached to that agent's tmux session |
| Model dropdown | Saves the choice to `tools/restart-protocol/agent-model-config.json`; applies on next start/restart |
| Switch account | Runs `claude auth logout; claude auth login` in a helper tmux session and opens the browser sign-in. Auth is **machine-wide** — one login covers all four agents; restart them afterwards so they adopt it |
| ⟳ Restart all | Stops and relaunches all four agents in sequence (~1–2 min) |

## If the computer shut off (cold start)

1. Power the Mac on. The Command Center and the tunnel come back by themselves.
2. Open https://command.houseloop.ai (or localhost:5180 at the desk).
3. Press **▶ Start** on each agent (or ⟳ Restart all). iTerm windows open automatically.

Manual fallback if the panel itself is dead — one iTerm tab per agent:

```bash
tmux new-session -s lee
cd /Users/zachspradling/Code/BossLoop-Gold && claude --model claude-fable-5 --dangerously-skip-permissions
```

Then type the wake-up line into Claude:

```
You are Lee. Read .claude/personas/lee.md and .claude/SOUL_LOCK.md FIRST.
```

Repeat for adam, benji, caleb — same commands, swap the name. And restart the panel itself with:

```bash
bash /Users/zachspradling/Code/BossLoop-Gold/tools/command-center/start.sh
```

## Switching accounts (the correction to the old guide)

The Claude login is **machine-wide, not per-pane** — you never log in four times. Running agents
keep their old token until restarted, which is why it can LOOK per-session.

1. Hit **Switch account** in the panel (or in any terminal: `claude auth logout` then
   `claude auth login` — note it is `claude auth login`; a bare `claude login` is not a command).
2. Pick the account in the browser. Verify with `claude auth status`.
3. Hit **⟳ Restart all agents** so everyone adopts the new account.

## tmux cheat sheet (manual fallback)

```
List all sessions          tmux ls
Attach to a session        tmux attach -t lee
Detach (keep it running)   Ctrl+B then D
Kill a frozen process      Ctrl+C
Kill one session           tmux kill-session -t lee
Kill ALL sessions          tmux kill-server        (nukes every agent — last resort)
```

## Troubleshooting the URL

**Public URL dead but localhost:5180 works → the TUNNEL is down, not the panel:**

```bash
launchctl unload ~/Library/LaunchAgents/com.bossloop.tunnel.plist
launchctl load ~/Library/LaunchAgents/com.bossloop.tunnel.plist
tail -20 /tmp/bossloop-tunnel.log
```

**Both dead → restart the panel** (`bash tools/command-center/start.sh`), then the tunnel.
