## ⭐ THE ARCHITECTURE — TWO SURFACES (Zach 8/12, the organizing principle)
This is **ONE massive feature = the Saved Search Dashboard**, expressed as TWO surfaces:
1. **THE AGENT SIDE — a big INCLUSIVE dashboard modal the agent WORKS OUT OF.** One coherent experience,
   NOT scattered floating modals: all saved searches · edit criteria · **Lists** · **selections** ·
   live-matches preview (scroll + filter + map + checkboxes) · send. Everything below (§1–§5) lives INSIDE
   this one modal.
2. **THE CLIENT SIDE — "go to the client view."** What the client sees ("Welcome back, Timothy") — the
   existing Client Dashboard (my-houseloop). The agent modal can jump to it; it is NOT the work surface.
The two are DISTINCT: the agent works out of the inclusive modal; the client view is the mirror of what the
client experiences. (Matches the locked nav: Search = agent working dashboard · Client Dashboard = client view.)

## 5. ⭐ THE BIG FEATURE — LIVE-MATCHES PREVIEW + SELECT (the core new capability)
When you click live matches (the **428** full results, OR today's new N), open a **preview** IN the dashboard:
- A **simple filter** at the top.
- A **carousel**: **VERTICAL scroll** through the homes (desktop), while each home's **PHOTOS swipe
  HORIZONTALLY** (like today's cards).
- A **checkbox per home** to select · **"Check all"** or pick the ones you want.
- e.g. 5 new homes today → 5 in a vertical scroll, select all or some.
- Intuitive endpoints: **"Send Zach 2 selected homes"** (super simple) OR **"Add to a custom shortlist."**
- **BOTH surfaces need this** — today's-new AND the full 428:
  - Today's-new works, but you open them **one at a time** (hence the scroll+select ask).
  - The full **428** has **NO way** to open in a view, see them on a **MAP**, filter, scroll fast, and
    select-to-send. That's the biggest gap — going through a client's houses to build a send list is painful.
- So: a fast, filterable, vertically-scrollable, per-home-photo-swipeable, **selectable** view of both
  today's-new and the full results, with an optional **MAP**, to build a client send-list.

## ⭐ THE TWO SEND TYPES (Zach 8/12) — supersedes the single-composer model
Zach, verbatim: *"there needs to be two types of send listings — send custom list, and that is where you add
notes and a message — or just a generic send listings… one is like a push through the houseloop chrome and the
other is send a custom list."*

Two DIFFERENT jobs, so two named intents, two composers, and **two different emails**. Per the LABEL LAW the
controls are named for the intent, never the mechanism.

| | **SEND LISTINGS** | **SEND CUSTOM LIST** |
|---|---|---|
| what it is | a templated push through the HouseLoop chrome | the personal, curated one |
| source | a SET — All matching · New since last sent · New today · Past 2 days · Past 7 days | homes hand-picked with the checkboxes (the selection tray) |
| notes | **none** — at most ONE optional opener line | a **note on each home** + a written personal message |
| the email | the **branded** HouseLoop template: navy header, house blocks, signature, footer | **zero chrome above the greeting** — his message in his own hand, house blocks below, branding only in the signature |
| voice | the system's (sans) | Zach's (handwritten) |

**One control, two intents.** The results header carries a single `Send to Timothy ▾` split-button. Its main
action names what it will actually do — `Send custom list (N)` when homes are checked, `Send listings`
otherwise. Its menu is split into the two labelled groups. The bottom selection tray is the custom-list path
by definition and its button reads **Send custom list (N)**.

**This KILLS the old "≤5 note fields, thumbnail-strip beyond that" degrade.** That workaround existed only
because one composer was trying to serve both jobs. It is gone: if you want notes you are on a custom list by
definition, and nobody hand-picks 428. The listings composer shows the set as a strip because it has no notes
BY DESIGN, not as a fallback — and it points the agent at the custom list when they need to say something
about a specific house.
