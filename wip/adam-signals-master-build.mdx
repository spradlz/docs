##### 1. THE JOURNEY OF ONE SIGNAL (the spine everything hangs on)

A phone call to the GMB line, end to end:

1. **THE DOOR** — (913) 320-0906, a row in the Numbers directory. It knows 4 things: what it is, its
   label, its carrier, and **which inbox it feeds** (Company). The door also carries the **marketing
   source** ("Google Business").
2. **THE REFLEX (inbox config — NEVER a workflow)** — the Company inbox's ring rule runs live, mid-call:
   ① the manager answers if it's an AI with Calls on (Myli, her voice persona + the inbox's situational
   prompt layer) → ② otherwise ring humans in order → ③ voicemail + recording → card. How the call is
   handled/dispositioned/spoken is 100% config: the inbox (situation) + the Voice page (engine + doctrine)
   + the agent card (personality). **Workflows never answer phones.**
3. **THE EVENT** — the call fires the existing door event `call_received` through `dispatchDoor` →
   the `hl_trigger_fire` ledger (Lee's live wiring: voice webhook, `lib/workflows/fire-door.ts`).
   The fire carries the door + inbox + contact-match state. Same ledger as every trigger in the CRM.
4. **THE MINT (identity gate — Lee's law, same law as Adam's)** — a signal creates a lead ONLY when it
   carries identity. A call carries a phone → phone-lookup dedupe: known number → activity on the
   existing lead (never a dupe); unknown → **mint a new lead, source = the door's source** (Google
   Business), under the **Company Inbox integration**.
5. **THE WORK** — the mint fires the Lead Sources machinery Lee built: the source's **Default Routing
   Rule** (owner + stage + default workflow) unless that event's seat overrides it; the seat's
   New-Lead / Existing-Lead **workflow arms** picked by the `created` flag (`lib/workflows/runtime.ts`).
   Welcome text, notify, assign — all HERE, in Lead Flow. Never in the inbox.
6. **THE RECEIPTS** — every step lands on the one activity spine (`hl_lead_activity` + run log +
   `hl_trigger_fire`), visible in: the inbox's stream, the lead's All feed, the AI Cockpit's live
   activity, and the source card's ⚡ Triggered count. One truth, four lenses.

**Sequential, never parallel.** Inbox events and lead-source events can't collide because the inbox
hands off at the mint. "Phone call received" is operational; "New lead created (source: Google
Business)" is lead-flow. Two different moments of the same journey.
