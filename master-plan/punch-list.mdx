| | means |
|---|---|
| ✅ | **done**, with a receipt named on the item |
| 🟦 | **built, awaiting prod proof** — real finished work sitting in the unpushed branch. **Not missing.** It ticks when the push lands and is verified |
| ☐ | **open** — not started, or not finished |
| ⤵ | **superseded** — overtaken by a later decision; the note names what absorbed it. These never roll forward |
| ⭐ YOURS | only you can close it — a decision, not a build |
