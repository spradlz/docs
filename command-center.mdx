The working boards live **in the CRM** at `crm.houseloop.ai/boards/<slug>` (CRM login required,
read-only). Claude.ai artifacts are scratch iteration only — the repo HTML is the truth and the CRM
page is the door. Boards are promoted deliberately via `tools/boards/promote.mjs`; this page is
regenerated by that tool on every promote. Do not edit it by hand.

**Signed documents live here, in the docs.** An artifact is account-locked scratch for iterating; the
moment a document is SIGNED it is promoted into this section as a real page, so any dev on any Claude
account reads the same signed truth. Living documents (the QA plan) are re-promoted in place.

**How it works:** `promote.mjs` copies the locked board HTML into `apps/houseloop-crm/boards/`,
stamps `manifest.json` (slug · title · sha256 · source), and regenerates this page. The CRM route
serves the exact file behind the existing session auth. `promote-doc.mjs` does the same for a signed
markdown document — it writes `docs-site/command-center/<slug>.mdx`, stamps `doc-manifest.json`, and
registers the page in the nav. Deploy = git push (the normal pipeline).
