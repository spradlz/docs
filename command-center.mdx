**How it works:** `promote.mjs` copies the locked board HTML into `apps/houseloop-crm/boards/`,
stamps `manifest.json` (slug · title · sha256 · source), and regenerates this page. The CRM route
serves the exact file behind the existing session auth. `promote-doc.mjs` does the same for a signed
markdown document — it writes `docs-site/command-center/<slug>.mdx`, stamps `doc-manifest.json`, and
registers the page in the nav. Deploy = git push (the normal pipeline).
