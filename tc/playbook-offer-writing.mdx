## Purpose

This is the complete process for assembling and writing a buyer's offer, written so Claude can execute it.
Follow the phases in order.

## PHASE 1 — Gather everything from the MLS

Do this in one trip. You will not be able to recover some of this later.

### 1.1 — MLS Data Sheet
1. Go to the MLS and find the subject property
2. Click **Print**
3. Select the **Client Full** version
4. Print to PDF
5. Save it

### 1.2 — Taxes Data Sheet
1. From the listing, click the **Realist Property Full Detail** link
2. Print to PDF
3. Save it

This document is the source for the **legal description** and the **parcel / tax ID** used later on the contract.

### 1.3 — Listing documents

Download from the listing's document section:

- **Seller's Disclosures** — always required
- **Lead-Based Paint Disclosure** — required if the home was built before 1978
- **Listing Offer Sheet** — the cover/offer-submission form some listing agents provide. If present, it must be filled out and becomes part of the contract package.
- Any additional documents the listing agent attached to the listing

<Warning>
**Gap check — do this immediately.** If the Seller's Disclosures are missing, or the Lead-Based Paint
Disclosure is missing on a pre-1978 home: **text the listing agent right away and request them.** Doing this
first means the documents arrive while you're writing the offer instead of holding up submission at the end.
</Warning>

### 1.4 — Earnest money "Deposited With"

**Save this now.** The escrow/title holder that earnest money is deposited with appears on the MLS listing
view, but it **does not print on the Client Full report**. Once you leave the MLS you won't find it in the
uploaded PDFs. Copy it into your notes for later entry on the contract.

### 1.5 — Listing agent contact information

1. Click the listing agent's name on the MLS listing
2. Copy their full information — you'll enter it in Loop Details in Phase 4

**If there is more than one listing agent**, determine which one is the main agent, in this order
(Ana, 2026-07-31):

1. **Read the private remarks on the MLS.** They usually name which of the two is the main listing agent.
   That is the agent whose details go into dotloop as the listing agent, and the one you send the offer to.
2. **Check the Listing Offer Sheet.** It sometimes names the main agent.
3. **Text both agents and confirm.** This is the *preferred* move when the first two do not answer it —
   not a last resort. Both agents' cell numbers are on the listing MLS under their names.
4. **Only if you still cannot find out — use LA2**, the second agent on the MLS data sheet.

<Note>
LA2 is the fallback, not the rule. Ana's exact words: *"the best is if the info is not found to text both
agents and confirm."* A wrong listing agent means the offer goes to someone who is not writing it up.
</Note>

### 2.1 — Create the loop

### 2.2 — Name the loop

Format:

```
Buyer Full Name(s) [Marital Status Code] - Property Address
```

**Buyer name rules:** First name + middle initial + last name. The middle name is always shortened to an
initial, but it is **always included**. Two buyers → both full names, same format.

**Marital status codes**

| Code | Meaning | Placement |
|---|---|---|
| **ASP** | A single person | After each name |
| **AMC** | A married couple (both spouses on the contract) | Once, at the end |
| **AMP** | A married person (married, spouse not on the contract) | After that buyer's name |

### 2.3 — Apply the template

Select the **2026 Spradling Buyer Template** — confirmed exact by Ana 2026-07-31. There are only three
templates to choose from; this is the one.

## PHASE 3 — Upload, organize, and rename documents

### 3.1 — Where documents go

All documents go under the **eXp – Writing the Offer Documents** category. Place each document in its correct
placeholder. If a document has no matching placeholder, still place it in that category area.

### 3.2 — Document order

1. Listing Offer Sheets
2. Spradling Group Buyers Offer Sheet
3. Real Estate Contract – Residential
4. Seller's Disclosures
5. Lead-Based Paint
6. MLS Data Sheet
7. Taxes Data Sheet

### 3.3 — Rename every document

Every uploaded document gets renamed to:

```
[Document Name] - [Property Address]
```

Examples:

```
Listing Offer Sheets - 6105 E 96th Terrace
Real Estate Contract Residential - 6105 E 96th Terrace
Sellers Disclosures - 6105 E 96th Terrace
MLS Data Sheet - 6105 E 96th Terrace
Taxes Data Sheet - 6105 E 96th Terrace
```

**No exceptions** — this keeps every loop consistent.

### 3.4 — Assign initials

On the **MLS Data Sheet** and the **Taxes Data Sheet**, assign buyer initials to the top of every page. Each
buyer initials each page. This confirms the buyers saw and read those pages.

## PHASE 4 — Fill out Loop Details ("View Details")

**Every field gets filled. No blanks.**

### 4.1 — Property information

- **Property address** — type it in manually.

<Warning>
**Do not use the address search/lookup.** Searching the address links your loop to the listing agent's loop,
and we do not want them connected.
</Warning>

- **Parcel / Tax ID** — from the Taxes Data Sheet
- **County**
- **Closing date** — required
- **Offer date** — optional

### 4.2 — Listing agent

Add Person → Role: **Listing Agent** → fill in all details.

MLS → loop field mapping. **Note the phone fields are crossed** — this is the easiest thing to get backwards:

| Loop field | Pull from MLS |
|---|---|
| **Cell Phone** | Agent Phone |
| **Phone** | Agent Office Phone |
| Company Name | Broker's name |
| Address | Broker's address |
| Email | Agent's email |
| Role | Listing Agent |

### 4.3 — Buyers

- Add each buyer as a **separate person**
- Enter the name **without** the marital status code

<Warning>
**Why:** buyers actually sign in the loop. If the marital status is in their name field, it gets pulled into
their signature block. We never want "ASP" or "AMC" appearing inside a buyer's signature.
</Warning>

- Fill in home address, phone, email

### 4.4 — Sellers

- Take seller names from the **Seller's Disclosures**
- Add them as **one single person entry** — even if there are two or more sellers
- Enter the name string **exactly** as it appears on the Seller's Disclosures, including the marital status

Example: `Matthew B. Vanley and Cassandra Vanley, a married couple`

- Role: **Seller**

**Why one entry:** we don't have the sellers' contact information and they aren't signing from our loop. This
entry exists only to populate the seller names on the contract.

## PHASE 5 — Fill out the forms

### 5.1 — Residential Real Estate Sale Contract

| Field | How to fill it |
|---|---|
| Seller names | Complete, with marital status, at the top — exactly as on the Seller's Disclosures |
| Buyer names | Full names, then **manually type** the marital status code after the names |
| Legal description | Copy and paste from the **Taxes Data Sheet** |
| Parcel / Tax ID | From the Taxes Data Sheet |
| Earnest money — Deposited With | The escrow/title holder saved from the MLS in Step 1.4 |
| Buyer is pre-approved — lender | Format: `Lender Name - Lender's Company` |
| Closing date | As agreed with the buyer |

**The manual marital status rule.** Because the marital status was deliberately left out of the buyers'
detail fields, it must be added **manually** to the buyer names on each contract and every top form.

- Both buyers, married, both on contract → names, then **AMC** at the end
- Single buyers → **ASP** after each name
- Married buyer, spouse not on the contract → that buyer's full name + **AMP**

### 5.2 — Exclusive Buyer's Agency Agreement

- **Price range** — use a broad bracket around the offer price. Round **down** to the nearest $100K below and
  **up** to the nearest $100K above. Example: offer of $250,000 → price range $200,000 – $300,000
- **Agreement term** — 6 months. Date the offer is written + 6 months.

### 5.3 — Affiliated Business Arrangement Disclosure (ABAD)

- **Date** — the date the offer is being written

### 5.4 — Listing Offer Sheet (if the listing agent provided one)

- Fill it out completely — it becomes part of the contract package
- Tax fields must be added and filled in manually

## Quick reference

**Marital status codes**

| Code | Meaning |
|---|---|
| ASP | A single person |
| AMC | A married couple |
| AMP | A married person (spouse not on contract) |

**Where marital status DOES appear**
- The loop name
- Manually typed on the buyer names on each contract and top form
- Inside the single combined seller entry (copied from Seller's Disclosures)

**Where marital status NEVER appears**
- The buyers' person/detail fields

**Naming convention**

```
[Document Name] - [Property Address]
```

## Things that are easy to get wrong

1. Typing the property address manually instead of searching it — searching links your loop to the listing agent's loop
2. **Cell Phone ↔ Phone are crossed** between MLS and the loop
3. Earnest money "deposited with" must be captured while you're still in the MLS
4. Marital status never goes in the buyers' detail fields
5. Sellers go in as **ONE** person entry; buyers go in **SEPARATELY**
6. Legal description comes from the **Taxes Data Sheet**, not the MLS Data Sheet

## THE BUILD — "Write Offer" in the loop (spec, not yet built)

> Everything above is the process as written. This section is the HouseLoop build that automates it.
> **Status: SPEC — not built. Nothing below is live yet.**

**The goal (Zach 2026-07-30):** a real **Write Offer** button on the loop. Click it, a form opens
**pre-filled** from the lead + the attached property, you confirm the offer terms, and the system assembles
the whole package, fills every form, and sends it for signature — the same way the buyer's agency send works
today. **API-callable**, so the AI clone can do it end-to-end without a human.

### What it needs from the system (already have vs. build)

| Input | Where it comes from | Status |
|---|---|---|
| Buyer name(s), phone, email, home address | the lead | **have** |
| Property address, parcel/tax ID, county, legal description | the loop's attached `Listing` + Taxes Data Sheet | **partly** — address yes; parcel/legal need the Realist sheet |
| MLS number | the `Listing` | **have** |
| Listing agent contact (crossed phone fields) | MLS | **build** — capture step |
| Earnest money "deposited with" | MLS listing view only | **build** — must be captured in Phase 1 or it is unrecoverable |
| Pre-approval letter, lender name + company | the lead's documents | **build** |
| Offer price, closing date, EMD, warranty, commission, possession, inspection period | **the Write Offer form** | **build** |

### The offer terms form

Pre-filled where we can, editable always. These are the terms that drive both the contract fill and the
client email:

Purchase Price · Earnest Money Deposit · Seller to Pay Home Warranty · Seller to Pay Buyer's Agent
Commission · Closing Date · Possession · Who pays buyer's closing costs · Inspection Period · Inspection
Negotiation (yes/no)

### The send — same rails as the buyer's agency

Reuse [Forms & E-Sign](/tc/forms) verbatim: fill → multi-party send → signing link → R2 archive → the loop
shows **Waiting on Signatures**. No new signing path.

### The client message (Zach's template, merge-fielded)

Sent as text **and** email alongside the signing link:

```
Hi {{buyer_first_name}},

I just shared the offer documents with you for your review and signature.

Here are the key terms of the offer:

Purchase Price: {{purchase_price}}
Earnest Money Deposit: {{earnest_money}}
Seller to Pay Home Warranty: {{home_warranty}}
Seller to Pay Buyer's Agent Commission: {{buyer_agent_commission}}
Closing Date: {{closing_date}}
Possession: {{possession}}
Buyers to Pay Their Own Closing Costs
Inspection Period: {{inspection_period}} days after acceptance of the offer
Inspection Negotiation: {{inspection_negotiation}}

Please let me know if you have any questions after reviewing the documents.
I'm happy to go over everything with you.
```

### Build order (proposed)

1. **Offer terms model** — one row per offer on the loop, so the terms are data, not prose.
2. **The Write Offer modal** — reuse `HlFormModal` + the existing property search; pre-fill from lead + loop.
3. **The document package** — the seven documents in the Phase 3 order, auto-renamed `[Document Name] - [Property Address]`.
4. **The fill** — contract, buyer's agency (with the price-bracket + 6-month term rules from 5.2), ABAD.
5. **The send** — existing multi-party send, unchanged.
6. **The message** — the template above, merge-filled, text + email.
7. **The API** — one call, so the clone can run 1-6 headlessly.
