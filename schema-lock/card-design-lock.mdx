## What this is

On 2026-07-30 Zach locked the universal design for **every card in the lead-detail feed** — messages, notes,
emails, calls, inquiries, registrations, website activity, appointments, tasks, documents, deals, AI actions,
system moves. It was designed the constitutional way (`UI_ITERATION_HTML_FIRST`): iterated as an HTML
wireframe, signed, then ported node-by-node and refined live on real leads the same day.

**The pinned wireframe:** `Docs/wireframes/card-chrome-locked-2026-07-30.html` (repo, version-pinned).
This page carries the FINAL law including the same-day refinements Zach ruled during the live walk.

## THE SENTENCE LAW — the one grammar

Every card is: **[family icon in a colored circle] + a plain-English sentence "[Who] [did what] [· the facts]"**
(+ a VIA chip when it came from a portal) · **date+time top-right, always** · **hover actions below the date,
star first** · **click the card → its family's tab**.

The verb phrase is **DATA — a column on the signed activity catalog** (`hl_activity_catalog.sentence`,
migration 0513, 127 kinds authored): "created a note", "changed the stage", "requested a tour". The renderer
is one dumb line: `who + the catalog's sentence + the payload facts`. A new kind writes its sentence in its
catalog row — no code, no pills, no drift. NULL sentence = the label renders atomically (insight/system kinds).

### Who is the "Who" (all Zach's exact rulings)

- **Full names, always**: "Msale Olongo requested a tour", "Zach Spradling created a note".
- **The WHO comes from the actor lane** (lead / agent / Myli / System) — never guessed from message direction.
- **Users ACT, strangers ARRIVE**: a known system user reads active ("Ana Spradling sent an email");
  an outside sender reads "Email received from John Nelson". The email thread API resolves the sender
  against `hl_users` (`sender_is_user`) so the card knows which grammar to speak.
- **The machine never takes a person's credit**: "System opened a document" was the SIGNER opening their
  e-sign link — the writer credits the lead (mig 0514 re-credited history). The multi-party completion
  event reads atomic: "Document fully executed" — a system observation, not a signature.
- **Pink #EC4899 (`--hl-ai-pink`) = Myli/AI only.** Purple is retired from the feed (email = teal #0F766E).
  System moves wear the mechanical Settings icon in slate.

### Every card names its OBJECT

- **Appointments**: title from `hl_appointments` + the schedule line —
  "Wednesday, Jul 29, 2026 · 11:00 AM – 1:00 PM · 116 se 8th street, Lees Summit MO · with Zach Spradling".
  Meta fallback keeps history when an appointment is deleted.
- **Email engagements**: "Bradley Bengel opened an email · *subject*" — resolved through the send-log id.
- **Documents**: "Zach Spradling sent a document for signature · Exclusive Buyer Agency Contract" (0515) ·
  "Bradley Bengel signed a document · *name*" · "Bradley Bengel opened a document · *name*".
- **Stage moves**: "changed the stage · First Appointment Set → First Appointment Met".
- **Calls**: "Outbound call to Msale Olongo · from your line · 1:52" — the person by NAME, number as fallback.
- **Myli's facts**: "Myli captured a new fact — Search Criteria", the slot underneath, the evidence quoted.
  Never the raw payload salad.
- **Comms provenance**: the from→to line ("from Msale · (816) 756-9634 → Zach Spradling") rides every
  message card, FUB-style.

## NO pills — not for users, not for kinds

The actor is plain bold text in the sentence. Kind pills ("Note Added", "Stage Changed", "Phone Call
Logged") are dead — **the icon IS the kind; VIA (source) is the only chip a card may wear.** Per-user
colors are whack-a-mole and banned forever.

## The chrome (top-right, every card)

- **Row 1, always visible**: date + time, ONE token (`CARD.date`), one format, same corner on every card
  type — compact rows, notes, emails, heroes.
- **Row 2, hover, below the date**: action icons, **☆ ALWAYS FIRST**; per-family extras follow
  (note: ✏ edit · 🗑 delete).

## Click-through — every row leads somewhere

Clicking any feed card opens its family's tab: note → Notes · appointment → Appointments · text/in-app →
Messages · call → Calls · task → Tasks · inquiry → Inquiries · home view → Website. A guard skips real
controls (links, buttons, the audio player) so they keep working.

## The email card — Gmail's grammar (Zach's ours-vs-Gmail ruling)

- **ONE icon** (the left-rail mail circle). The avatar double-icon is dead.
- Line 1: **the sentence** ("Email received from John Nelson" / "Zach Spradling sent an email").
- Line 2: "to Trish.redenbaugh, zach, bradleybengel, Ana **▾**" — the triangle opens the Gmail details
  block: from / to (every full address) / date / subject.
- Chrome: date + ☆ top-right only. **Reply · Reply All · Forward · ⋯ (Delete/Block) at the BOTTOM** of the
  expanded message.
- **Full expansion** — no height cap, no inner scroll; the feed scrolls.
- **Sender names are captured at sync** (mig 0512 `from_name`) and resolved from-name → `hl_users` → bare
  address; old rows self-heal as new mail arrives.
- **Attachments**: paperclip row per genuine file (name + size + View + Download) riding
  `GET /api/email/attachment`. **Inline signature images** (cid: parts) are rewritten to the attachment
  endpoint so signatures render like Gmail — inline parts never clutter the file list.
- **FUB twin dedupe**: FUB mirrors the same email as a `[CONTENT HIDDEN]` row; redacted fub rows are
  dropped only when the native capture exists within ±2 minutes.
- **All-feed match**: activity rows may reference an email by `gmail_message_id` — the email map keys BOTH
  ids so the real card always renders, never a fallback; the fallback itself is atomic and can never
  invent a speaker.

## The locked pieces that must not be touched

- **Home-card links**: Zillow-origin → `Look up on HouseLoop · View on Zillow`; HouseLoop-origin →
  `View on HouseLoop` only.
- **In-app Zillow messages always wear the little round Zillow circle** — hero included.
- **Registrations are ALWAYS hero** with a big round SOURCE icon (HouseLoop / Zillow / generated
  color+initial for unbranded sources).
- **Hero shapes** for inquiries/tour requests (icon chip on photo, quote box, VIA chip).

## How to add or change a card (the maintenance rule)

1. **New kind?** Catalog row first: key, label, **sentence**, icon, color, `card_layout`. The feed inherits
   everything.
2. **Recolor / re-word a family?** One catalog `UPDATE` migration + regenerate badges, same commit.
3. **New card SHAPE or action set?** STOP — that's a wireframe change. Edit the pinned HTML, get Zach's
   re-lock, then port. A shape that exists only in React is vibe code.
4. **A card that reads wrong is a DATA bug first**: check the sentence column and the actor lane before
   touching a component.

## Why this exists

By 2026-07-30 the feed had drifted into pill soup and word salad: three pills on a note, stars over dates,
purple on system moves, "Msale SMS Received" non-sentences, "Bradley Bengel replied by email" on another
man's email, "System opened a document" for a human signature. Zach walked real leads screen by screen and
locked one grammar; every fix became either a catalog row or an honest writer — which is the whole design:
**the card is data, the renderer is dumb, and drift has nowhere to live.**
