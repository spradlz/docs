## Inbox — the landing screen (`/m` → `/m/inbox`)

One row per person, newest first, showing **only what needs a response** — texts, calls, tour
requests and new leads in one list (Zach locked 7/26: the app opens on everything that needs an
answer, not just texts). Row = avatar · name · what happened · when.

Shipped as a node-by-node port of **screen 1** of the locked wireframe below
(`apps/houseloop-crm/app/m/inbox/page.tsx`).

## Thread — one person, every channel (`/m/inbox/[leadId]`)

Texts, calls, emails, Zillow in-app messages and requests **interleaved in time on one
screen**. A plain message renders as a bubble; calls and requests render as event rows.
Shipped as **screen 2** of the same wireframe
(`apps/houseloop-crm/app/m/inbox/[leadId]/page.tsx`).
