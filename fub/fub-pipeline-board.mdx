## The four-hop chain — every signal passes all four

**capture → transit → filing → notification.** A green check on any one hop says nothing about the others (the 8/18 excavation found all four broken at once, each invisibly).

1. **Capture:** FUB webhooks (push, most signals) · the Chrome sweep (in-app messages — no API exists) · the activity heartbeat pointing the scraper (saved searches — their webhook died Apr 2026).
2. **Transit:** webhook classes land on Railway directly; scraper classes relay Camp David → Railway (~minutes; slice 3 removes this hop).
3. **Filing:** every signal becomes ONE card in `hl_activity_log` via `logActivity` — deduped on (lead, source_table, source_id), the actor stamped by the shared converter (direction-aware since 8/18: inbound names the lead, outbound never does).
4. **Notification:** the notify weld evaluates at filing; freshness-gated so catch-up filings never ring stale bells.
